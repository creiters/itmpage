Decentralized PWA & Deep-Tech Initiative

Built by Team CreITers | For 42 Prague Peers

Empowering students with an offline-first learning intranet, decentralized P2P systems, a custom pure-stack architecture, and hardware/security bridges—built with zero external frameworks.

Radical Minimalism: Pure Systems Architecture

Key Concepts

  • Zero External Dependencies: 100% control over the entire execution stack.
  • Universal Data Format: All data (User, Learning, Templates, Offline, Online) is structured and exchanged exclusively as JSON.
  • Internal Architecture: Custom, internally built JavaScript mini MVVM framework for clear code separation and high performance.

The Pure Stack

  • Frontend Core: Pure, Clear JavaScript, semantic HTML5, modern CSS3.
  • Low-Level Compute Engine: C compiled to WebAssembly (WASM) & WASI for high-performance offline logic.
  • Persistence: Client-side IndexedDB for local-first storage.

Engine Workflow: Decentralized P2P Mesh

1. Omnivore Offline Ingestion

Download all materials → Universal JSON IndexedDB cache.

2. Local Vectorization & RAG

Custom C/WASM modules index local text into vector stores directly inside the browser sandbox.

3. Decentralized Sync (WebRTC)

Peer-to-Peer synchronization exchanges data (notes, tests, evaluations) directly over the local cluster network without external servers.

4. Client-Side Intelligence

Local WebLLM runs client-side (RAG/LangChain concepts) to generate flashcards and interactive quizzes from the localized knowledge base.

Deep Tech Divisions

Security Architecture: Local-First Isolation

  • Zero Telemetry & Attack Surface: No centralized databases or external tracking.
  • WASM Sandboxing: C execution isolated within browser memory boundaries.
  • Encrypted P2P: WebRTC DTLS/SRTP end-to-end encryption for intra-campus comms.
  • Defensive Training: A hands-on lab for studying exploit vectors and secure design.

Physical Computing: 42 Core to Hardware

  • Browser-to-Hardware: Interfacing C/WASM directly with microcontrollers (ESP32, STM32, Pi) via Web Serial/Bluetooth.
  • Telemetry Vis: Real-time dashboards rendered with pure Canvas/WebGL.
  • Embedded Systems: Bridging 42 C/C++ memory management into physical robotics.
