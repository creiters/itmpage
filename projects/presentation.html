Project CyberPear

Decentralized PWA & Deep-Tech Initiative

Built by Team CreITers | For 42 Prague Peers.

Empowering students with an offline-first learning intranet, decentralized P2P systems, a custom pure-stack architecture, and hardware/security bridges—built with zero external frameworks.

[ Initialize Core ]

01 // Radical Minimalism & P2P Engine

Pure Systems Architecture

  • Zero External Dependencies: 100% control over the entire execution stack.
  • Universal Data Format: All data is structured and exchanged exclusively as JSON.
  • Internal Architectural Framework: Use of a custom, internally built JS mini MVVM.

The Pure Stack

  • Frontend Core: Pure, Clear JavaScript, semantic HTML5, modern CSS3.
  • Low-Level Compute Engine: C compiled to WebAssembly (WASM).
  • Persistence: Client-side IndexedDB for local-first storage.

Decentralized P2P Mesh

  • Omnivore Offline Ingestion: JSON IndexedDB cache.
  • Local Vectorization & RAG: Custom C/WASM modules index local text.
  • Decentralized Sync: WebRTC Peer-to-Peer synchronization.
  • Client-Side Intelligence: Local WebLLM runs client-side to generate flashcards.

02 // Deep Tech Divisions

Security Architecture: Local-First

  • Zero Telemetry & Attack Surface: No centralized databases or third-party servers.
  • WASM Sandboxing: C execution isolated within browser memory boundaries.
  • Encrypted P2P Data Channels: WebRTC DTLS/SRTP end-to-end encryption.
  • Practical Defensive Training: Hands-on lab for studying exploit vectors.

Physical Computing: Hardware Bridge

  • Browser-to-Hardware Control: Interfacing C/WASM directly with microcontrollers (ESP32, STM32, Arduino, Pi).
  • Telemetry & Visualization: Real-time dashboards rendered with pure Canvas/WebGL.
  • Embedded Systems Foundations: Bridging 42 C/C++ memory management into robotics.

03 // CreITers Ecosystem

  • Solutions for Your Environment: Privacy-respecting, offline-first for 42 Prague.
