Project CyberPear

Decentralized PWA & Deep-Tech Initiative

Built by Team CreITers | For 42 Prague Peers.

Empowering students with an offline-first learning intranet, decentralized P2P systems, a custom pure-stack architecture, and hardware/security bridges—built with zero external frameworks.

[ Initialize Core ]

01 // Radical Minimalism & P2P Engine

Pure Systems Architecture

  • Zero External Dependencies: 100% control over the entire execution stack.
  • Universal Data Format: All data (User, Learning, Templates, Offline, Online) is structured and exchanged exclusively as JSON.
  • Internal Architectural Framework: Use of a custom, internally built JavaScript mini MVVM for clear code separation and high performance.

The Pure Stack

  • Frontend Core: Pure, Clear JavaScript, semantic HTML5, modern CSS3.
  • Low-Level Compute Engine: C compiled to WebAssembly (WASM) & WASI for high-performance offline logic.
  • Persistence: Client-side IndexedDB for local-first storage.

Decentralized P2P Mesh

  • Omnivore Offline Ingestion: Download all materials → Universal JSON IndexedDB cache.
  • Local Vectorization & RAG: Custom C/WASM modules index local text into vector stores inside the browser.
  • Decentralized Sync: WebRTC Peer-to-Peer synchronization exchanges data directly over the local cluster network.
  • Client-Side Intelligence: Local WebLLM runs client-side to generate flashcards and quizzes, querying the localized vectorized knowledge base.

02 // Deep Tech Divisions

Security Architecture: Local-First

  • Zero Telemetry & Attack Surface: No centralized databases, third-party servers, or external tracking.
  • WASM Sandboxing: C execution isolated within browser memory boundaries.
  • Encrypted P2P Data Channels: WebRTC DTLS/SRTP end-to-end encryption for all intra-campus communication.
  • Practical Defensive Training: Platform acts as a hands-on lab for studying exploit vectors and secure design.

Physical Computing: Hardware Bridge

  • Browser-to-Hardware Control: Interfacing C/WASM directly with microcontrollers (ESP32, STM32, Arduino, Raspberry Pi) via Web Serial and Web Bluetooth.
  • Telemetry & Visualization: Real-time dashboards rendered with pure Canvas/WebGL.
  • Embedded Systems Foundations: Bridging 42 C/C++ memory management and multithreading into physical robotics.
